# h0 

## ohjelmankääntäminen

Tein yksinkertaisen C++-ohjelman tiedostoon helloworld.cpp.

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

## ohjelman kääntäminen

   Ohjelma käännettiin komennolla:

   g++ helloworld.cpp -o helloworld

   Ohjelma suoritettiin komennolla:

   ./helloworld
