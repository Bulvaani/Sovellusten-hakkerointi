## ohjelmankääntäminen

Tein yksinkertaisen C++-ohjelman tiedostoon nano helloworld.cpp. linux ympäristössä

    #include <iostream>

    int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
    }

## ohjelman kääntäminen

   Ohjelma käännettiin komennolla:

       $g++ helloworld.cpp -o helloworld

       ei tulostetta

   Ohjelma suorittaminen

        $./helloworld

        Tuloste:

        Hello, World!
