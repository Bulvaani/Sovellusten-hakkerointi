# H6 Onkohan tämä turvallinen käyttää?

Tapo C200 v3 Tietoturva-analyysi

1. Johdanto

Tutkimuksessa analysoitiin tp linkin tapo C200 v3 kameran firmware binääri ja flash muistidump tietoturvaongelmien löytämiseksi.

2. Käytetyt työkalut

tp ink-decrypt, binwalk, strings, xxd, openssl, Debian Linux 13 virtualBox ympäristössä.

3. Analyysi

Firmware purettiin tp link-decrypt-työkalulla (RSA-2048 salaus). binwalk analyysillä löydettiin Linux kernel (MIPS, versio 3.10.14), Squashfs-tiedostojärjestelmä sekä salattu konfiguraatio osio. Sama rakenne löytyi myös flash-muistidumpista.

4. Löydetyt haavoittuvuudet

gdbserver tuotantofirmwaressa — Debuggeri ei kuulu tuotantolaitteeseen. Mahdollistaa etädebuggoinnin ja mielivaltaisen koodin suorittamisen.

Kovakoodatut salausavaimet — Kaikilla C200-kameroilla on sama rootfs-salausavain (TP_LINK88i667gnt). Hyökkääjä voi purkaa ja muokata minkä tahansa C200-kameran firmwaren.

Command injection -riski — Pääbinääri suorittaa shell-komentoja (execute_shell_cmd, popen) ilman varmistettua syötesuodatusta.

Puuttuva binary hardening — NX, Stack Canary, ASLR ja RELRO puuttuvat kokonaan, mikä helpottaa muistikorruptio-haavoittuvuuksien hyödyntämistä.

Vanha kernel — Linux 3.10.14 (2013) ilman tietoturvapäivityksiä.

5. Johtopäätös

Kamera on kohtuullisen turvallinen tavallisessa kotikäytössä, koska hyökkäys vaatii pääsyn samaan verkkoon tai fyysisen pääsyn laitteeseen. Sensitiiviseen käyttöön kamera ei sovellu. Suositus: pidä kamera erillisessä IoT-verkossa.
